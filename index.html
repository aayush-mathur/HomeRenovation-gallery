    About this gallery & sharing

    This gallery is public by the owner's choice. Anyone can view and download the published images and interactive 3D geometry. No sign-in is required. Editable Blender scenes, original reference files and private project history are not included in this website.

    Publish only the generated gallery\dist directory, never the repository, editable Blender scenes, or reference files. The selected web GLB is intentionally included.

    The interactive viewer is bundled locally; loading it does not contact a model-hosting service. It requires a browser with WebGL support. If unavailable, the rendered reference remains usable.

    From the repository root on Windows, build with py -3 scripts\build_gallery.py. Preview with py -3 -m http.server 8000 --bind 127.0.0.1 --directory gallery\dist, then open http://127.0.0.1:8000. On other systems, use python3 instead of py -3. Rebuild after changing renders or manifests.

    Missing proposal manifests are omitted. If a manifest reports a generation state, it must be complete; unfinished generations fail the build and leave the previous gallery unchanged.

    Tap a render to enlarge it. Use Previous / Next or the left / right arrow keys; Escape closes the viewer. Native browser zoom remains available. Open the full image for browser-native zoom or saving.
